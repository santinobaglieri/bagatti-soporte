# soporte.bagatti.tech

Sitio de posventa de **Bagatti**: manuales, ficha técnica, garantía, mayorista y contacto.
Los QR impresos en las cajas apuntan acá, así que la URL no se cambia.

Deep links de los QR:
- `/#k9r-plus` → micrófonos inalámbricos K9-R+
- `/#qx300c` → trípode extensible QX300C

Sitio estático, sin build. Se publica solo con GitHub Pages al pushear a `main`.
Para actualizar un manual: editar `index.html`, commit, push.

Tienda: https://www.bagatti.tech
